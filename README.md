# Автоматизация генерации и оценки качества тестовой документации с использованием LLM

Проектная работа (Вариант 1): создание системы автоматической генерации тестовой документации и оценки её качества с использованием связки Python 3, PyTorch и локальной LLM через Ollama. Система оптимизирована для стабильной работы на ноутбуках с **8 ГБ оперативной памяти**.

---

## Структура проекта

```text
test_generator_project/
│
├── data/                      # Автоматически сгенерированные датасеты
│   └── dataset.json           # Обучающий датасет с хорошими и плохими кейсами
│
├── outputs/                   # Сгенерированные артефакты отчёта
│   ├── test_results.json      # Результаты оценки тест-кейсов в формате JSON
│   ├── metrics_distribution.png # График распределения метрик (matplotlib + seaborn)
│   └── report.md              # Итоговый отчёт о тестировании в формате Markdown
│
├── src/                       # Исходный код модулей проекта
│   ├── __init__.py            # Инициализатор пакета Python
│   ├── dataset_generator.py   # Генерация эталонного датасета через Ollama
│   ├── generator.py           # Генерация целевых тест-кейсов через Ollama
│   ├── evaluator.py           # NLP-модель на PyTorch (rubert-tiny2) для оценки качества
│   └── reporter.py            # Создание JSON, визуализация и сборка Markdown-отчёта
│
├── main.py                    # Главный исполняемый скрипт пайплайна
├── requirements.txt           # Зависимости проекта
└── .gitignore                 # Игнорируемые файлы для Git
```

## Требования и системные ограничения
- **ОС:** Windows / macOS / Linux
- **Оперативная память (RAM):** от 8 ГБ
- **ПО:**

  - Ollama (с установленной моделью `qwen2.5:1.5b`)

## Инструкция по установке и запуску

### Шаг 1. Установка и запуск Ollama
1. Установите Ollama, если она еще не установлена.
2. Скачайте легковесную модель `qwen2.5:1.5b`, оптимизированную для 8 ГБ RAM:
   ```bash
   ollama pull qwen2.5:1.5b
   ```
3. Убедитесь, что сервер Ollama запущен в фоновом режиме (при установке он обычно запускается автоматически). Проверить его доступность можно, открыв в браузере [http://localhost:11434](http://localhost:11434).

### Шаг 2. Настройка виртуального окружения и зависимостей
1. Клонируйте репозиторий или откройте папку проекта в терминале.
2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   ```
   * Активация на Windows:
     ```bash
     venv\Scripts\activate
     ```
   * Активация на macOS / Linux:
     ```bash
     source venv/bin/activate
     ```
3. Установите необходимые зависимости из файла `requirements.txt`:
   ```bash
   pip install -r requirements.txt
   ```

### Шаг 3. Запуск пайплайна
Запустите главный исполняемый скрипт:
```bash
python main.py
```

Скрипт последовательно выполнит следующие этапы:
1. Сгенерирует эталонный датасет с хорошими и плохими сценариями через Ollama и сохранит его в `data/dataset.json`.
2. Сгенерирует целевые тест-кейсы для формы авторизации (описание, ожидаемый результат, граничные значения).
3. Прогонит тест-кейсы через легковесную NLP-модель `cointegrated/rubert-tiny2` (PyTorch) для оценки 4 метрик: читаемость, чёткость целей, покрытие сценариев и согласованность.
4. Сформирует и сохранит все артефакты в папку `outputs/`.

---

## Описание сгенерированных артефактов (`outputs/`)
После успешного выполнения программы в папке `outputs/` появятся:
1. **`test_results.json`** — структурированные результаты тестирования и оценки сценариев.
2. **`metrics_distribution.png`** — визуализированный график средних значений метрик качества, построенный с помощью библиотек `matplotlib` и `seaborn`.
3. **`report.md`** — итоговый отчёт в формате Markdown, содержащий общую статистику, ссылку на график и таблицу со списком сценариев.
